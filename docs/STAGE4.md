# 4단계 — 기지, 모집소, 50층, 유산·도감

> GDD 15장 마일스톤 4. 완료 기준: **전체 루프 플레이 가능**. 세 번에 나눠 진행합니다.

| 단계 | 내용 |
|---|---|
| **4-1** | 골드, 기지 마을 화면, 시설 6개(최대 Lv10) + 건설 시간, 모집소(영웅 등급), 튜토리얼, 테스트 모드 |
| 4-2 | 11~50층 (오크 · 거미 · 인간 · 오우거, 50층 탑의 주인 용), 구간별 새 전투 규칙 |
| 4-3 | 죽은 영웅의 유산 (기여도 = 첫 돌파 층 ×5 + 보스 처치 ×20 + 레벨 ×2), 몬스터 도감 + 죽은 영웅 도감 |

## 4-1 들어간 것

| 항목 | 내용 |
|---|---|
| 기지 화면 | 마을 그림 위에 건물 6채 (숙소·모집소·대장간·병원·훈련장·연금소). 짓지 않으면 빈 터, 공사 중이면 비계 |
| 건설 | 최대 Lv10, 골드(+ Lv3부터 재료), 대기 시간 1분~24시간, 동시 1개 (광고로 1번 2개), 광고 1번 -30분 |
| 골드 | 탑 첫 클리어 60×층 / 재도전 25×층, 던전 10×층, 무기 분해 |
| 영웅 등급 | 일반~초월. 개체값·특성 보정. 카드와 상세에서 이름이 등급색 |
| 모집소 | 하루 무료 1 + 광고 2, 레벨별 등급 확률, 모집하면 진형 빈칸에 자동 배치 |
| 대장간 | 기지 안 시설로 이동. 레벨에 따라 제작 난이도 해금, 무기 분해(골드) 추가 |
| 병원 | 중상·기력 회복 속도 |
| 훈련장 | 영웅을 맡기면 시간당 경험치 (최대 8시간, 레벨 상한 = 최고 클리어 층) |
| 연금소 | 기력 물약·치료 물약(영웅 상세에서 사용), 힘·수호의 영약(다음 전투 1번) |
| 튜토리얼 | 시작 영웅 랜덤 2명 → 탑 1층 (져도 죽지 않음) → 모집소 무료 건설 → 1명 무료 모집. 가야 할 탭에 빨간 점, 말풍선 안내 |
| 1·2층 | 2명으로 시작하므로 1층 고블린 2마리, 2층 3마리로 조정 |
| 테스트 모드 | 영웅 탭 "테스트 모드": 모든 층·던전 바로 도전, 정찰 정보 공개, 시설 즉시 건설, 자원 +, 전원 회복. 출시 전 제거 |
| 광고 | 광고 SDK는 5단계. 지금은 누르면 바로 보상 |

## 남은 것 (4-1)
- 모집 연출, 건물 레벨별 외형 변화
- 건설·골드·물약 수치는 4-2 이후 50층 기준으로 다시 맞춤
