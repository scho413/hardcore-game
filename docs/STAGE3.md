# 3단계 — 던전 + 재료 + 대장간 + 피로도

> GDD 15장 마일스톤 3. 완료 기준: **재료를 모아 무기를 만들고, 영웅에게 쥐여주는 순환 확인**

## 들어간 것

| 항목 | 내용 |
|---|---|
| 던전 (던전 탭) | 재료별 3곳 × 깊이 3단계. 사망·중상 없음, 패배하면 보상만 없음 (GDD 6) |
| 재료 | 금속(구리 광석·철 광석·미스릴), 목재(참나무·흑단·세계수 가지), 마석(마석 조각·마석·순수 마석). 단계 1~3 |
| 탑 보상 | 층 클리어 시 재료. 첫 클리어는 더 많이, 8층부터 2단계 재료, 5·10층 첫 클리어는 상위 재료 추가 |
| 피로도 | 티켓 대신. 최대 6, 탑 +3 · 던전 +2 → 쉬지 않으면 탑 2번 / 던전 3번. 피로 1당 능력치 -5%, 5분에 1씩 회복 (GDD 3.2.1) |
| 대장간 (기지 탭) | 재료 확인, 직업 선택, 재료 단계 선택, 필요 재료·최대 등급·등급표, 보관함 |
| 직업 전용 무기 | 기사 장검과 방패(금속4), 전사 전투 도끼(금속3+목재1), 궁수 장궁(목재4), 마법사 마법 지팡이(목재2+마석2), 사제 성스러운 홀(마석2+금속2) |
| 미니게임 | ① 가열: 누르고 있으면 온도 상승, 움직이는 초록 구간에 머무르기(4초) ② 망치질: 왕복하는 표시를 가운데에서 4번 탭(점점 빨라짐) ③ 담금질: 가속하며 차오르는 게이지를 초록 구간에서 탭 |
| 등급 | 일반·고급·희귀·영웅·전설 (공격력 +6/12/20/30/45% + 직업별 부가 효과). 세 단계 평균 점수로 결정. 재료 단계가 상한 (1단계 희귀, 2단계 영웅, 3단계 전설), 상한은 85% 이상 |
| 장착 | 영웅 상세 → 무기 칸 → 같은 직업 무기 목록에서 선택 / 해제. 장착하면 영웅 그림의 무기 색이 등급색으로 바뀜 (영웅 등급 이상은 반짝임) |
| 무기 소실 | 영웅이 죽으면 무기도 사라짐. 결과 화면에 "… 소실", 일대기·추모의 벽에 "마지막 무기" |
| 재료는 먼저 소모 | 미니게임 시작 시 재료를 소모하고 저장 (중간에 꺼도 되돌릴 수 없음, 전투 결과 선저장과 같은 원칙) |

## 던전 구성 (초안, 시뮬레이터 기준)

레벨 = 적 수준인 무작위 영웅 5명 기준 승률 (`npm run sim`).

| 던전 | 얕은 곳 (Lv2) | 중간 (Lv5) | 깊은 곳 (Lv8) |
|---|---|---|---|
| 버려진 광산 · 금속 | 100% | 100% | 68% |
| 어두운 숲 · 목재 | 100% | 97% | 56% |
| 마석 동굴 · 마석 | 100% | 100% | 86% |

보상: 얕은 곳 1단계 3~5개, 중간 1단계 2~3 + 2단계 2~3, 깊은 곳 2단계 2~3 + 3단계 1~2. 승리 시 경험치는 탑의 절반.

## 확인 방법

1. 기지 탭: 시작 재료(구리 8 · 참나무 6 · 마석 조각 4)로 바로 무기를 만들어 볼 수 있음
2. 영웅 탭 → 영웅 상세 → 무기 "장착"
3. 던전 탭에서 재료 파밍 → 출전한 영웅의 피로가 쌓이고, 피로가 모자라면 진형 카드에 "던전 불가"/"탑 불가"
4. 탑에서 무기를 든 영웅이 죽으면 결과 화면에 무기 소실

## 남은 것 / 다음 단계 후보

- 던전 전용 배경 (지금은 탑 배경 재사용)
- 미니게임 손맛(효과음·진동)은 사운드 단계에서
- 던전·탑 보상량, 피로 회복 속도는 4단계(모집소·경제)와 함께 다시 조정
