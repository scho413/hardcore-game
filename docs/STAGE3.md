# 3단계 — 던전 + 재료 + 대장간 + 기력

> GDD 15장 마일스톤 3. 완료 기준: **재료를 모아 무기를 만들고, 영웅에게 쥐여주는 순환 확인**
> 첫 구현 후 같은 날 개편: 대장간 난이도 6단계·6등급·파손, 무기 개별 수치·특수 능력·내구도, 기력 10, 던전 1~10층·소탕

## 들어간 것

| 항목 | 내용 |
|---|---|
| 기력 | 영웅마다 최대 10. 탑 -5 · 던전 -3. 줄어든 1당 능력치 -3%, 6분에 1 회복 (GDD 3.2.1) |
| 던전 | 재료별 3곳 × **1~10층**, 10층 보스 (오우거 / 놀 우두머리 / 리치). 쓰러지면 승패와 관계없이 중상, 사망 없음 |
| 던전 진행 | 층마다 첫 클리어 재료 ×2, 던전별 최고 층 표시, 보스 처치는 일대기에 기록 |
| 소탕 | 클리어한 층은 결과만 바로 받음. 지금 파티 평균 레벨 ≥ 그 층을 깬 파티의 평균 레벨일 때만. 기력 소모·전투 계산은 그대로 |
| 변수 | 희귀 몬스터(황금 변종) 5% → 재료 ×3, 보물 상자 10% |
| 대장간 난이도 | 쉬움(자동·일반) / 보통 / 어려움 / 전설 / 신화 / 초월. 난이도마다 재료 단계·양, 최고 등급, 파손 확률(10 / 30 / 50%, 만점이면 절반)이 다름 |
| 미니게임 | 가열·망치질·담금질 + 신화 이상 **각인**. 난이도가 오를수록 판정 수가 늘고 구간이 좁아지고 움직임. 판정 하나마다 등급 확률 막대가 위 등급 쪽으로 이동 |
| 등급 | 일반 · 고급 · 상급 · 전설 · 신화 · 초월 |
| 무기 수치 | 같은 등급도 공격력이 범위 안에서 무작위(상위 25%면 ★), 부가 옵션 0~3개 무작위 (체력·방어·속도·치명타·치유) |
| 특수 능력 | 전설 이상: 기사 불굴, 전사 흡혈, 궁수 급소, 마법사 연쇄, 사제 기적. 신화·초월은 강화, 초월은 특수 능력 하나 더 |
| 내구도 | 100. 탑 -10, 던전 -5, 쓰러지거나 패배하면 -10 더. 0이면 효과 없음 → 대장간에서 수리 |
| 무기 소실 | 영웅이 죽으면 함께 소실. **탑에서 쓰러졌다가 살아남으면 20% 확률로 무기가 부서짐** |
| 장착 | 영웅 상세 → 무기 칸에서 장착·교체·해제. 내구도와 특수 능력 표시. 영웅 그림의 무기가 등급색 |

## 시뮬레이터 (`npm run sim`)

던전 n층에 레벨 n인 무작위 영웅 5명 (무기 없음) 기준 승률.

| 던전 | 1~6층 | 7층 | 8층 | 9층 | 10층 보스 |
|---|---|---|---|---|---|
| 버려진 광산 | 100% | 98% | 69% | 65% | 67% |
| 어두운 숲 | 97~100% | 94% | 96% | 92% | 69% |
| 마석 동굴 | 100% | 78% | 84% | 67% | 57% |

탑 10층(고블린 왕)에 레벨 10 파티: 무기 없음 57% → 전원 일반 71% → 상급 94% → 전설 이상 100%.
무기가 강하게 작용하므로 11층 이후 구간은 무기를 전제로 맞춥니다.

## 확인 방법

1. 기지 탭: 시작 재료(구리 12 · 참나무 10 · 마석 조각 8)로 쉬움~어려움 제작 가능. 전설 이상은 던전 4층 이후 재료 필요
2. 미니게임 중 아래 확률 막대가 판정마다 움직임. 끝나면 파손 판정 → 등급 공개
3. 영웅 탭 → 영웅 상세 → 무기 "장착"
4. 던전 탭: 층을 하나씩 열고, 깬 층은 "소탕"
5. 대장간 무기 목록에서 내구도 확인·수리

## 남은 것

- 던전 10층 보스 처치 시 다음 탑 구간 "소문" (11층 이후 구간을 만들 때)
- 던전 전용 배경, 미니게임 효과음·진동
- 재료 드롭량·수리 비용·기력 회복 속도는 4단계(모집소·경제)와 함께 조정
