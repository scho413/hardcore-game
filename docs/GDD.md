## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 픽셀아트 수집형 RPG, 자동전투, 탑 등반 |
| 화면 | 세로형 (portrait), 한 손 플레이 |
| 플랫폼 | Android 우선 (이후 iOS 검토) |
| 기술 | Phaser 3 + TypeScript + Vite, Capacitor로 Android 패키징 |
| 수익 | 최소 과금: 광고 제거(유료) + 보상형 광고 |
| 출시 범위 | **25층** (이후 업데이트로 100층까지 확장) |

**한 줄 소개**: 한 번 죽으면 영원히 사라지는 영웅들과, 직접 두드려 만든 무기로 탑을 오르는 게임.

**핵심 감정**: 영웅을 잃을지도 모른다는 긴장감, 그리고 "그 층에 들어가기로 한 건 나"라는 책임감.

**IP 주의**: 원작(픽미업)에서 영감만 얻습니다. 세계관, 캐릭터 이름, 고유 설정은 가져오지 않습니다.

## 2. 핵심 게임 루프

```
던전 탐사 → 재료 획득 → 무기 제작(미니게임) → 영웅 장착
    → 탑 등반 → 귀환 시 보상 확정 → 기지 업그레이드 → 반복
```

| 장소 | 역할 | 영구 사망 |
|---|---|---|
| 던전 | 재료 파밍. 상대적으로 안전 | 없음 (피로도만 증가) |
| 탑 | 진행, 보스, 핵심 보상 | **있음** |

## 3. 영웅

### 3.1 영구 사망
- 사망한 영웅은 다시 나타나지 않습니다.
- 모든 영웅은 **랜덤 생성**되어 세상에 하나뿐입니다 (이름, 외형 조합, 직업, 특성).
- 사망한 영웅은 도감의 **추모의 벽**에 기록됩니다.

### 3.2 상태
| 상태 | 설명 | 회복 |
|---|---|---|
| 정상 | 출전 가능 | — |
| 피로 | 탑/던전 다녀온 후. 출전 시 능력치 감소 | 시간 경과 (숙소) |
| 중상 | 전투에서 쓰러졌지만 파티가 승리 | 시간 경과 (병원) |
| 사망 | 영구 제거 | 불가 |

### 3.3 쓰러짐 규칙 (핵심)
- 전투 중 체력 0 → **쓰러짐** (즉사 아님)
- 전투 **승리** 시: 쓰러진 영웅은 **중상**으로 생존
- 전투 **패배** 시: 쓰러진 영웅은 **전원 사망**
- 패배 후 **광고 시청으로 1명만 부활** 가능 (하루 제한)

### 3.4 직업 (초기안)
| 직업 | 역할 | 기본 위치 |
|---|---|---|
| 기사 | 탱커, 도발 | 전열 |
| 전사 | 근접 딜러 | 전열 |
| 궁수 | 원거리 딜러 | 후열 |
| 마법사 | 광역 딜러, 속성 | 후열 |
| 사제 | 힐러 | 중열/후열 |

### 3.5 특성 (영웅당 1~2개, 예시)
- **겁쟁이**: 체력 30% 이하일 때 회피율 증가
- **광전사**: 동료가 쓰러지면 공격력 증가
- **강철 피부**: 받는 피해 감소, 속도 감소
- **빠른 회복**: 중상·피로 회복 시간 단축
- **형제**: 특정 영웅과 같은 파티일 때 버프 *(이후)*

### 3.6 성장
- 전투 경험치로 레벨업. 한 번의 죽음이 몇 시간짜리 손실이 되지 않도록 성장 속도를 빠르게 유지합니다.

## 4. 전투 (자동)

- **5인 파티** vs 적 웨이브, 완전 자동. 전투 중 개입 없음.
- 층당 전투 시간 목표: **30초~1분**
- 화면 배치: 위쪽 적, 아래쪽 아군

### 4.1 전투 전 전략 요소
| 요소 | 내용 | 범위 |
|---|---|---|
| 진형 | 전열 2 / 중열 1 / 후열 2. 전열이 먼저 맞음 | MVP |
| 직업 조합 | 특정 조합에 시너지 보너스 | MVP |
| 장비 배분 | 에이스 몰아주기 vs 분산 | MVP |
| 로스터 운영 | 피로도 때문에 영웅을 돌려 써야 함 | MVP |
| 특성 | 같은 직업이라도 쓰임새가 다름 | MVP |
| 속성 상성 | 불 / 물 / 바람 (+ 무속성) | MVP |
| 정찰 | 다음 층 적 정보·위험도 표시 | MVP |
| 소모품 | 포션, 부적 등 한정 슬롯 | 이후 |
| 전투 AI 설정 | 영웅별 행동 우선순위 | 이후 |

### 4.2 기본 수치 (초안, 밸런싱 대상)
- 스탯: HP, 공격력, 방어력, 속도, 치명타율
- 행동 순서: 속도 기반 게이지
- 피해: `공격력 × 스킬 배율 × 상성 배율 − 방어력 보정`
- 상성 배율: 유리 1.3 / 불리 0.7

## 5. 탑

### 5.1 구조 (출시: 25층)
| 층 | 내용 |
|---|---|
| 일반 층 | 일반 몬스터 전투 |
| 5, 15층 | 중간보스 |
| 10, 20층 | 메인보스 |
| 25층 | 특별보스 (출시 버전 최종) |

확장 시: 100층까지, 특별보스 25/50/75/100층.

### 5.2 진행 규칙
- **전투 중 후퇴 없음.**
- 층 클리어 후 선택: **계속 올라가기 / 귀환하기**
- 선택 화면에 다음 층 **정찰 정보**와 **위험도** 표시
- 탑에서 얻은 보상은 **귀환해야 확정**. 전멸 시 이번 도전 보상 소실.
- **체크포인트**: 메인보스(10, 20층) 클리어 후 다음 도전은 해당 층부터 시작 가능
- 탑 도전 후 참여 영웅은 **피로** 상태

## 6. 던전

- 재료 종류별 던전 (예: 광산 → 금속, 숲 → 목재/가죽, 동굴 → 마석)
- 하루 입장 티켓 제한. 광고로 추가 티켓.
- 자동전투, 영구 사망 없음. 피로도만 증가.
- 소탕(즉시 완료) 기능 *(이후)*

## 7. 대장간 (무기 제작)

### 7.1 흐름
1. 무기 종류 선택 (검, 활, 지팡이, 방패 등)
2. 재료 선택 → **등급 상한** 결정
3. 미니게임 3단계 → 상한 안에서 **실제 등급** 결정

### 7.2 미니게임
| 단계 | 조작 | 판정 |
|---|---|---|
| 가열 | 길게 눌러 온도를 목표 구간에 유지 | 구간 유지 시간 |
| 망치질 | 움직이는 바가 초록 구간일 때 탭 (3~5회) | 정확도 |
| 담금질 | 적절한 순간에 탭 | 타이밍 |

### 7.3 등급
일반 → 고급 → 희귀 → 영웅 → 전설

- 재료 등급이 최대 등급을 제한합니다. (예: 일반 재료는 아무리 잘해도 희귀까지)
- 이후: 분해, 자동 제작(평균 등급 보장)

## 8. 모집소 (영웅 뽑기)

- **유료 뽑기 없음.**
- 하루 무료 1회 + 광고 2회
- 게임 내 재화(탑/던전 보상)로 추가 뽑기
- 천장: 10회 뽑기마다 고등급 1명 보장
- 보조 수급: 탑 특정 층에서 영웅 구출
- 원칙: **영웅 유입 속도 > 평균 사망 속도**가 되도록 밸런싱

## 11. 수익 모델

### 11.1 유료
- **광고 제거 (영구)**: 전면 광고 제거 + 보상형 광고 혜택을 광고 없이 즉시 수령

### 11.2 보상형 광고
| 위치 | 혜택 | 제한 |
|---|---|---|
| 모집소 | 추가 뽑기 | 하루 2회 |
| 탑 패배 | 영웅 1명 부활 | 하루 제한 (수치 TBD) |
| 던전 | 입장 티켓 추가 | 하루 제한 |
| 대장간 | 미니게임 재도전 | 제작당 1회 |
| 던전 보상 | 재료 2배 | 하루 제한 |

광고 부활은 "판단 실수에 대한 보험"이지 영구 사망의 무효화가 아닙니다.

## 12. 화면 구성

하단 탭: **기지 / 영웅 / 탑 / 던전 / 도감**

- 기지: 픽셀아트 시설 화면, 시설 클릭으로 이동, 일일 리셋 정보
- 영웅: 로스터 목록, 필터, 영웅 상세
- 탑: 파티 편성 → 전투 → 층 사이 선택 → 귀환 결과
- 던전: 던전 선택 → 편성 → 전투 → 결과
- 도감: 영웅 / 추모의 벽 / 몬스터

## 15. 개발 마일스톤

| 단계 | 목표 | 완료 기준 |

| **1** | 자동전투 + 탑 10층 | 전투를 보는 게 재밌는지 확인 가능 |
