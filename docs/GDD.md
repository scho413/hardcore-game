## 2. 핵심 게임 루프

```
던전 탐사 → 재료 획득 → 무기 제작(미니게임) → 영웅 장착
    → 탑 등반 → 귀환 시 보상 확정 → 기지 업그레이드 → 반복
```

| 장소 | 역할 | 영구 사망 |
|---|---|---|
| 던전 | 재료 파밍. 상대적으로 안전 | 영구 사망 없음, 쓰러지면 중상 (기력 -3) |
| 탑 | 진행, 보스, 핵심 보상 | **있음** |

## 3. 영웅

### 3.1 영구 사망
- 사망한 영웅은 다시 나타나지 않습니다.
- 모든 영웅은 **랜덤 생성**되어 세상에 하나뿐입니다 (이름, 종족, 외형 조합, 직업, 특성).
- 목표: 추모의 벽을 봤을 때 **모든 영웅의 얼굴이 서로 달라 보일 것**. 외형이 완전히 같은 영웅은 생성하지 않습니다.
- 사망한 영웅은 도감의 **추모의 벽**에 기록됩니다.

### 3.2 상태
| 상태 | 설명 | 회복 |
|---|---|---|
| 정상 | 출전 가능 | — |
| 기력 소모 | 탑/던전 다녀온 후. 출전 시 능력치 감소 (3.2.1) | 시간 경과 (숙소) |
| 중상 | 전투에서 쓰러졌지만 파티가 승리 | 시간 경과 (병원) |
| 사망 | 영구 제거 | 불가 |

### 3.2.1 기력 *(2026-11-07 추가, 같은 날 개편)*
- 영웅마다 기력 최대 **10**. 탑 도전 **-5**, 던전 **-3** → 탑은 연속 2회, 던전은 3회까지 (탑 1 + 던전 1도 가능)
- 남은 기력이 출전 비용보다 적으면 그 콘텐츠에 출전 불가
- 기력이 줄어든 채로 출전하면 줄어든 1당 **체력·공격력·방어력 -3%** (예: 기력 6/10 → -12%)
- **6분에 1씩 회복** (0에서 1시간이면 가득). 이후 숙소 업그레이드로 단축
- 중상과 별개로 계산 (중상 회복 중에도 기력은 회복)

### 3.3 쓰러짐 규칙 (핵심)
- 전투 중 체력 0 → **쓰러짐** (즉사 아님)
- 전투 **승리** 시: 쓰러진 영웅은 **중상**으로 생존
- 전투 **패배** 시: 쓰러진 영웅은 **전원 사망**
- 패배 후 **광고 시청으로 1명만 부활** 가능 (하루 제한)

### 3.4.1 종족 *(2026-11-07 추가)*
종족은 직업과 별개입니다 (예: 드워프 마법사, 고양이 수인 기사). 종족마다 고유 특성과 **천적 계열**이 있습니다.
천적 계열의 적에게는 피해 +25%.

| 종족 | 고유 특성 | 천적 계열 |
|---|---|---|
| 인간 | 빠른 성장: 경험치 +20% | 녹색족 (고블린, 홉고블린, 오크) |
| 바바리안 | 공격력 +10%, 체력 50% 이하일 때 공격력 +20% | 거인 (오우거, 트롤) |
| 엘프 | 속도 +8%, 치명타 +5%p, 체력 -8% | 언데드 (해골, 구울, 리치) |
| 드워프 | 방어력 +12%, 체력 +10%, 속도 -10% | 용족 (용, 리자드맨, 뱀족) |
| 수인 · 토끼 | 10% 확률로 공격 회피 | 야수 (늑대 수인, 하이에나 수인, 놀) |
| 수인 · 고양이 | 치명타 +8%p | 야수 |
| 수인 · 강아지 | 받는 치유 +25%, 방어력 +5% | 야수 |
| 수인 · 곰 | 체력 +18%, 공격력 +5%, 속도 -8% | 야수 |

악마·괴수·인간(범죄집단) 계열에는 천적 종족이 없습니다.

### 3.5 특성 *(2026-11-07 개편)*
특성은 **좋음 / 나쁨 / 양면** 세 종류이고, 특성마다 수치가 있습니다.

**태어날 때**
1. 특성 개수: 0개 / 1개 / 2개 각 1/3
2. 특성마다 종류: 좋음 / 나쁨 / 양면 각 1/3, 종류 안에서 특성은 균등 확률
3. 수치: 좋음 최대 +20%, 나쁨 최대 -15%. 수치가 클수록 드물게

| 좋음 | 확률 | 나쁨·양면 | 확률 |
|---|---|---|---|
| +5% | 40% | 5% | 45% |
| +10% | 30% | 10% | 35% |
| +15% | 20% | 15% | 20% |
| +20% | 10% | | |

**살면서**
- 특성은 **최대 4개**. 꽉 차면 새 특성은 생기지 않음
- **같은 특성은 다시 붙지 않음**. 서로 반대인 특성(날렵함 ↔ 느림보 등)도 같이 붙지 않음
- 특정 사건이 있을 때만 확률로 새 특성 획득 (트라우마, 역전의 용사, ○○ 사냥꾼)
- 나쁜 특성은 전투를 거치며 확률로 **극복** (사라지거나 좋은 특성으로 바뀜). 극복은 칸을 쓰지 않으므로 4개가 꽉 차도 일어남

**목록 (초안)**

| 종류 | 특성 | 효과 (v = 수치) |
|---|---|---|
| 좋음 | 날렵함 / 튼튼함 / 힘셈 / 단단함 | 속도 / 체력 / 공격력 / 방어력 +v |
| 좋음 | 예리함 | 치명타 +v/2 %p |
| 좋음 | 빠른 회복 | 중상 회복 시간 -v×2.5% |
| 나쁨 | 겁쟁이 | 체력 30% 이하일 때 v 확률로 행동 포기 |
| 나쁨 | 허약함 / 느림보 | 체력 / 속도 -v |
| 나쁨 | 서툰 손 | v 확률로 공격이 빗나감 |
| 나쁨 | 이기적임 | 주는 치유·버프 효과 -v×2 |
| 나쁨 | 엄살 | 중상 회복 시간 +v×5% |
| 나쁨 | 고소공포증 | 5층 이상에서 공격력·방어력 -v |
| 양면 | 비만 | 체력 +v, 속도 -v |
| 양면 | 광전사 | 쓰러진 아군 1명당 공격력 +v, 방어력 -v |
| 양면 | 강철 피부 | 받는 피해 -v, 속도 -v |
| 양면 | 무모함 / 신중함 | 공격력 ±v, 방어력 ∓v |
| 전투 획득 (나쁨) | 트라우마(계열) | 동료가 그 계열 적에게 쓰러지는 것을 봄. 그 계열에게 주는 피해 -v, 받는 피해 +v |
| 전투 획득 (좋음) | 역전의 용사 | 보스 층에서 빈사로 생존. 체력 30% 이하일 때 공격력 +v |
| 전투 획득 (좋음) | ○○ 사냥꾼 | 한 계열 적을 많이 처치. 그 계열에 피해 +v |

**극복 (초안)**
- 겁쟁이 → **용기** (빈사일 때 공격력 +v): 빈사 상태로 살아남은 승리에서 확률
- 이기적임 → **헌신** (주는 치유·버프 +v×2): 동료가 쓰러진 승리에서 확률
- 트라우마(계열) → 사라짐: 그 계열과의 전투를 아무도 쓰러지지 않고 이기면 확률
- 그 외 나쁜 특성 → 사라짐: 승리할 때마다 낮은 확률

### 3.7 일대기 *(2026-11-07 추가)*
영웅마다 사건을 기록합니다. 영웅 상세와 추모의 벽에서 볼 수 있습니다.
- 모집, 첫 출전, 층 첫 돌파, 보스 처치, 레벨 고비(5, 10, 15…)
- 중상, 특성 획득·극복, 동료의 죽음 목격
- 마지막 전투: 몇 층에서, 어떤 적의 어떤 공격에 쓰러졌는지
- 요약: 출전 횟수, 처치 수, 최고 도달 층

### 3.6 성장
- 전투 경험치로 레벨업. 한 번의 죽음이 몇 시간짜리 손실이 되지 않도록 성장 속도를 빠르게 유지합니다.

### 4.1.1 진형 *(2026-11-07 추가)*
| 진형 | 배치 (전열/중열/후열) | 효과 |
|---|---|---|
| 기본 | 2 / 1 / 2 | 없음 |

### 4.2 기본 수치 (초안, 밸런싱 대상)
- 스탯: HP, 공격력, 방어력, 속도, 치명타율
- 행동 순서: 속도 기반 게이지
- 피해: `공격력 × 스킬 배율 × 천적 배율 − 방어력 보정`
- 천적 배율: 1.25 (천적 계열 상대), 그 외 1.0

## 5. 탑

### 5.1 구조 (출시: 25층)
| 층 | 내용 |
|---|---|
| 일반 층 | 일반 몬스터 전투 |
| 5, 15층 | 중간보스 |
| 10, 20층 | 메인보스 |
| 25층 | 특별보스 (출시 버전 최종) |

확장 시: 100층까지, 특별보스 25/50/75/100층.

### 5.1.1 구간 테마 *(2026-11-07 개편)*
**10층마다 테마가 바뀝니다.** 한 구간은 한 계열의 적과 그 변형으로 채웁니다.
테마가 바뀌면 유리한 종족(천적)이 바뀌므로 파티를 새로 짜고 영웅을 새로 키우게 됩니다. 다음 테마는 **예고하지 않습니다** (정찰은 영웅을 보내서).

| 구간 | 테마 | 계열 | 적 | 5층대 중간보스 | 10층대 보스 |
|---|---|---|---|---|---|
| 1~10 | 고블린 소굴 | 녹색족 | 고블린 전사·궁수·주술사·폭탄병, 늑대 기수, 홉고블린 | 고블린 족장 | 고블린 왕 |
| 11~20 | 미정 | | | | |
| 21~25 | 미정 (25층 특별보스) | | | | |

적 아이디어 (테마에 맞춰 골라 씀, 전부 쓸 필요 없음):
괴수(슬라임, 거미족, 샌드웜), 녹색족(고블린, 홉고블린, 오크), 인간(범죄집단), 야수(늑대 수인, 하이에나 수인, 놀),
악마(임프, 서큐버스), 언데드(해골, 구울, 리치), 용족(리자드맨, 뱀족, 용), 거인(오우거, 트롤)

### 5.2 진행 규칙
- **전투 중 후퇴 없음.**
- **한 번에 한 층.** 층을 클리어하면 **무조건 귀환**합니다 (연속 등반 없음). *(2026-11-07 변경)*
- 도전 가능한 층: 클리어한 층 전부 + 바로 다음 층. 낮은 층은 신규 영웅 육성용.
- **처음 도전하는 층은 정보 없음** (적 구성·위험도 숨김). 한 번 도전한 층(실패 포함)부터 정찰 정보와 위험도 표시 *(2026-11-07)*
- 미리 알고 싶으면 영웅 1명만 보내서 정찰 (패배 시 그 영웅은 사망). 정보의 대가는 영웅의 목숨
- 보상은 층 클리어 시 바로 확정 (재료). 첫 클리어는 많이, 재도전은 절반. 전멸 시 보상 없음
- 탑 도전은 기력 -5 (3.2.1)
- ~~체크포인트~~: 한 층씩 귀환하므로 불필요 *(2026-11-07 삭제)*

## 6. 던전 *(2026-11-07 구체화, 같은 날 개편)*

- 재료 종류별 던전 3개. 던전마다 **1~10층**, 10층은 던전 보스

| 던전 | 재료 | 적 | 10층 보스 |
|---|---|---|---|
| 버려진 광산 | 금속 (구리 → 철 → 미스릴) | 슬라임, 거미족, 트롤 | 오우거 |
| 어두운 숲 | 목재 (참나무 → 흑단 → 세계수 가지) | 늑대 수인, 하이에나 수인, 놀 | 놀 우두머리 |
| 마석 동굴 | 마석 (조각 → 마석 → 순수 마석) | 임프, 구울, 뱀족, 서큐버스 | 리치 |

- 층 구성은 고정 (다시 가면 같은 적). 클리어한 층 + 다음 층까지 도전 가능
- 재료: 1~3층 1단계, 4~6층 1·2단계, 7~9층 2·3단계, 10층 3단계 많이
- 자동전투, **영구 사망 없음**. 쓰러진 영웅은 승패와 관계없이 **중상**. 패배하면 보상 없음
- 기력 -3 (3.2.1). 경험치는 탑의 절반

### 6.1 노가다가 되지 않게 *(2026-11-07)*
- **진행(성과)**: 층마다 첫 클리어 보상 **재료 ×2**, 던전별 최고 층 기록, 10층 보스 처치는 일대기에 기록
- **소탕**: 한 번 클리어한 층은 전투 화면 없이 결과만 받음. 기력은 똑같이 소모, 실제 전투를 계산하므로 질 수도 있음
  - 조건: 지금 파티 **평균 레벨 ≥ 그 층을 클리어했던 파티의 평균 레벨** (가장 낮은 기록). 30레벨 파티가 깬 층을 1레벨 파티가 소탕할 수 없음
- **변수**: 희귀 몬스터(황금 변종) 5% → 재료 ×3, 보물 상자 10% → 재료 한 번 더
- **탑과 연결**: 던전 처치 수도 사냥꾼 특성 조건에 포함. 이후 10층 보스 처치 시 다음 탑 구간 **소문** (11층 이후 구간을 만들 때)

## 7. 대장간 (무기 제작) *(2026-11-07 구체화, 같은 날 개편)*

### 7.1 흐름
1. 무기 종류 선택 = **직업 전용 무기**
2. **난이도** 선택 → 나올 수 있는 등급, 재료, 파손 확률 결정
3. 미니게임: 판정 하나에 성공할 때마다 **위 등급 확률이 오름** (화면에 등급별 확률 막대가 실시간으로 바뀜)
4. 끝나면 **파손 판정** → 통과하면 **등급 추첨**
5. 보관함에 들어가고, 영웅 상세에서 같은 직업 영웅에게 장착

| 직업 | 무기 | 기본 재료 | 전설 이상 특수 능력 |
|---|---|---|---|
| 기사 | 장검과 방패 | 금속 4 | 불굴: 전투당 1번, 쓰러질 피해를 받아도 버팀 (체력 1 / 15% / 30%) |
| 전사 | 전투 도끼 | 금속 3 + 목재 1 | 흡혈: 준 피해의 8 / 12 / 16% 회복 |
| 궁수 | 장궁 | 목재 4 | 급소: 치명타 피해 +40 / 60 / 80% |
| 마법사 | 마법 지팡이 | 목재 2 + 마석 2 | 연쇄: 20 / 30 / 40% 확률로 다른 적에게 60% 피해 |
| 사제 | 성스러운 홀 | 마석 2 + 금속 2 | 기적: 전투당 1번, 쓰러질 아군을 체력 25 / 35 / 50%로 일으킴 |

특수 능력 수치는 전설 / 신화 / 초월. 초월은 다른 직업의 특수 능력이 하나 더 (전설 수치)

### 7.2 난이도
| 난이도 | 등급 | 재료 | 파손 (만점 시) | 판정 | 미니게임 |
|---|---|---|---|---|---|
| 쉬움 | 일반 고정 | 1단계 ×1 | 없음 | 0 | 없음 (자동 제작) |
| 보통 | 일반~고급 | 1단계 ×1 | 없음 | 5 | 가열 1, 망치질 3, 담금질 1 |
| 어려움 | 일반~상급 | 1단계 ×2 | 없음 | 6 | 가열 1, 망치질 4, 담금질 1 · 구간이 좁고 빠름 |
| 전설 | 일반~전설 | 2단계 ×2 | 10% (5%) | 8 | 가열 2, 망치질 5, 담금질 1 · 구간이 움직임 |
| 신화 | 일반~신화 | 3단계 ×1 | 30% (15%) | 9 | + 각인 1 |
| 초월 | 일반~초월 | 3단계 ×2 | 50% (25%) | 10 | 망치질 6 · 표시 속도가 출렁임 |

- 등급 확률은 미니게임 점수(판정 평균)에 비례해 "시작"에서 "만점"으로 옮겨감. 예) 전설: 시작 일반 70 / 고급 22 / 상급 7 / 전설 1 → 만점 일반 1 / 고급 20 / 상급 49 / 전설 30
- 파손 확률도 점수에 비례해 줄어듦 (만점이면 절반). 파손되면 재료도 사라짐

| 판정 | 조작 |
|---|---|
| 가열 | 길게 눌러 온도를 움직이는 목표 구간에 유지 (3초) |
| 망치질 | 왕복하는 표시가 초록 구간일 때 탭. 칠 때마다 빨라짐 |
| 담금질 | 점점 빨리 차오르는 게이지가 목표 구간일 때 탭 |
| 각인 | 줄어드는 고리가 표식에 겹칠 때 탭 |

### 7.3 등급과 능력치
일반 → 고급 → 상급 → 전설 → 신화 → 초월

| 등급 | 공격력 (무기마다 범위 안에서 무작위) | 부가 옵션 | 특수 능력 |
|---|---|---|---|
| 일반 | +4~8% | 0 | - |
| 고급 | +9~14% | 1 | - |
| 상급 | +15~22% | 2 | - |
| 전설 | +23~32% | 2 | 직업 특수 능력 |
| 신화 | +33~45% | 3 | 직업 특수 능력 (강화) |
| 초월 | +46~60% | 3 | 직업 특수 능력 (최강) + 다른 특수 능력 1 |

- 부가 옵션: 체력, 방어력, 속도, 치명타 (사제는 치유·버프 추가) 중 무작위, 등급이 높을수록 수치도 큼
- 공격력이 범위 상위 25%면 이름에 ★

### 7.4 내구도와 소실
- 내구도 **100**. 탑 -10, 던전 -5, 쓰러지거나 패배하면 **-10 더**
- 0이 되면 무기 효과 없음 → 대장간에서 **수리** (같은 단계 주재료, 닳은 만큼 × 등급 배수)
- **무기는 영웅과 운명을 같이합니다.** 영웅이 죽으면 장착한 무기도 소실 (추모의 벽에 마지막 무기 기록)
- **탑에서 쓰러졌는데 살아남으면 20% 확률로 무기가 부서져 사라짐** (던전은 해당 없음)
- 장착한 무기는 영웅 그림에 등급 색으로 표시 (전설 이상은 반짝임)

## 13. 아트 & 사운드

- 픽셀아트, 캐릭터 약 32×32
- 에셋 팩 구매 + 색/디테일 수정 방식 (직접 제작 최소화)
- 영웅 외형은 부위 조합으로 랜덤 생성하며 **성별 → 종족 → 직업** 순으로 정해집니다 *(2026-11-07 개편)*
  - **성별** (남/여 랜덤): 체형 폭, 머리 모양 후보, 수염(남성만), 속눈썹·입술색(여성), 이름
  - **종족**: 의상 스타일과 체형, 머리 장비·옷 색 후보
    - 인간: 직업별 정통 복장 (갑옷, 로브, 뾰족 모자 등)
    - 바바리안: 털가죽·맨팔·전투 물감, 뿔·뼈 장식. 마법사·사제는 짐승 두개골 머리장식의 주술사
    - 엘프: 날씬한 체형, 숲색 튜닉과 긴 망토, 잎 관·서클릿·날개 투구
    - 드워프: 작고 다부진 체형, 쇠와 가죽, 둥근 쇠 투구·뿔 투구·고글, 석궁
    - 수인: 조끼·반바지·맨발(털), 두건·꽃 장식, 종족 귀는 항상 보임
  - **직업**: 무기와 작은 장신구 (인간만 의상 전체)
  - 그 외: 머리 모양·색, 눈·눈썹·입, 표식(흉터, 주근깨, 전투 물감 등)
  - 에셋 팩은 **부위별 레이어가 분리된 팩**(몸/머리/옷/무기가 같은 프레임 크기의 별도 시트)을 우선 검토. 레이어를 겹쳐 그리고 색은 팔레트 교체로 바꿉니다.
  - 완성형 캐릭터만 있는 팩이면: 직업별 변형 몇 종 중 랜덤 + 팔레트 교체로 대체
- 영웅 얼굴 아이콘: 스프라이트의 머리 부분을 잘라 사용 (추모의 벽, 목록)
- 사운드: 에셋 구매
