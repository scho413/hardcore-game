# 1단계 — 자동전투 + 탑 10층

> GDD 15장 마일스톤 1. 완료 기준: **전투를 보는 게 재밌는지 확인 가능**

## 들어간 것

| 항목 | 내용 |
|---|---|
| 자동전투 | 5인 파티 vs 적, 속도 기반 행동 게이지, 전투 중 개입 없음 |
| 진형 | 전열 2 / 중열 1 / 후열 2. 탑 화면에서 두 영웅을 탭해 자리 교체 |
| 직업 5종 | 기사(도발), 전사(강타), 궁수(연사·저격), 마법사(원소 폭풍·광역), 사제(치유·성역) |
| 속성 상성 | 불 → 바람 → 물 → 불 (유리 1.3 / 불리 0.7), 무속성은 상성 없음 |
| 피해 공식 | `공격력 × 스킬 배율 × 상성 배율 − 방어력 × 0.5` (최소 20% 보장), 치명타 1.5배 |
| 탑 10층 | 5층 중간보스(오우거), 10층 메인보스(잿불 드레이크) |
| 정찰 | 다음 층 적 구성·속성·특징 + **위험도**(현재 진형으로 120회 가상 전투 → 낮음/보통/높음/매우 높음) |
| 연출 | 근접 돌진, 투사체, 광역 내려찍기, 피격 반짝임, 데미지 숫자(치명/약점/저항), 쓰러짐, 화면 흔들림 |
| 배속 | 1 / 2 / 3배속 (기기에 저장) |
| 저장 | 클리어 층, 파티 레벨, 진형을 브라우저에 자동 저장 |

## 1단계 임시 규칙 (2단계에서 교체)

- 영웅은 고정 5명. 랜덤 생성·영구 사망은 2단계.
- 쓰러진 영웅은 그 전투에서만 이탈. 다음 전투에서는 전원 체력 회복.
- 층을 처음 클리어하면 파티 전원 +1레벨. 패배하면 같은 층 재도전.
- 층 사이 "계속/귀환" 선택은 2단계. 지금은 한 층씩 탑 화면으로 돌아옴.
- 직업 시너지, 특성은 아직 없음.

## GDD에 없던 결정 (검토 필요)

- **속성 순환 방향**: 불 > 바람 > 물 > 불
- **광폭화**: 90번째 행동부터 적 공격력 1.6배, 200번째 행동에서 패배 처리 (전투가 끝없이 늘어지는 것 방지)
- **위험도 표시**: 승률 숫자는 숨기고 등급만 보여줌

## 밸런스 (npm run sim, 각 층 1000판, 레벨 = 층)

| 층 | 승률 | 평균 행동 수 | 승리 시 생존 | 승리 시 남은 HP |
|---|---|---|---|---|
| 1 | 100% | 18 | 5.0 | 91% |
| 2 | 100% | 27 | 5.0 | 84% |
| 3 | 100% | 27 | 5.0 | 75% |
| 4 | 99% | 45 | 3.9 | 52% |
| 5 중간보스 | 82% | 70 | 3.3 | 22% |
| 6 | 100% | 35 | 4.3 | 57% |
| 7 | 98% | 53 | 3.3 | 40% |
| 8 | 91% | 50 | 3.6 | 39% |
| 9 | 93% | 47 | 3.4 | 43% |
| 10 메인보스 | 69% | 65 | 2.6 | 17% |

의도: 1~3층은 연습, 4층부터 영웅이 쓰러지기 시작, 보스는 이겨도 아슬아슬하게.
2단계에서 쓰러짐 = 중상/사망이 되면 "승리 시 생존" 숫자가 곧 긴장감입니다.

난이도 손잡이: `src/data/monsters.ts`의 `ENEMY_ATK_SCALE`, `FLOOR_GROWTH`, 보스 기본 수치.
