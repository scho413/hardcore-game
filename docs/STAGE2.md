# 2단계 — 영웅 생성 + 영구 사망 + 쓰러짐 규칙 + 귀환 + 추모의 벽

> GDD 15장 마일스톤 2. 완료 기준: **영웅을 잃는 긴장감 확인**

## 들어간 것

| 항목 | 내용 |
|---|---|
| 랜덤 영웅 | 이름(음절 조합), 직업, 속성, 특성 1~2개, 개체값(능력치 ±8%), 외형 |
| 외형 | 직업별 기본 몸 + 피부색 4 × 머리색 6 × 옷 색 5 + 장식(수염·안대·흉터·머리띠·투구 깃털) |
| 얼굴 아이콘 | 스프라이트의 머리 부분을 잘라서 사용 (결과 화면, 추모의 벽) |
| 특성 7종 | 겁쟁이, 광전사, 강철 피부, 빠른 회복 (GDD) + 날렵함, 튼튼함, 예리함 (추가) |
| 쓰러짐 규칙 | 승리 → 쓰러진 영웅 **중상** (5분 뒤 회복). 패배 → 쓰러진 영웅 **전원 사망** |
| 귀환 | 층을 클리어하면 무조건 귀환. 클리어한 층 + 다음 층 중에서 골라 도전 |
| 경험치 | 층 클리어 시 참여 영웅 전원 `100 × 층` 획득, 다음 레벨까지 `100 × 현재 레벨` |
| 추모의 벽 | 도감 탭. 얼굴, 이름, 직업·레벨, 최고 도달 층, 사망 층, 날짜 |
| 화면 | 하단 탭 (영웅 / 탑 / 도감, 기지·던전은 "준비 중"), 영웅 목록·상세, 진형 칸별 영웅 선택창 |

## 외형 — 에셋 팩으로 바꿀 때

지금 구조(`src/art/heroLook.ts`)는 이미 에셋 팩 방식과 같습니다.

1. **직업별 기본 몸** — 지금: 코드 속 16×16 그림 / 팩: 직업별 몸 스프라이트 시트
2. **팔레트 교체** — 피부·머리·옷 색을 바꿀 글자(색)를 직업마다 지정 / 팩: 같은 방식으로 시트 색 교체, 또는 회색조 레이어에 틴트
3. **장식 레이어** — 지금: 얼굴 좌표에 픽셀을 덧그림 / 팩: 장식 레이어 시트를 같은 좌표에 겹쳐 그림
4. **얼굴 아이콘** — 직업별 머리 영역을 잘라냄. 팩이면 머리 영역 좌표만 맞추면 됨

에셋 팩을 고를 때 **부위가 레이어로 나뉜 팩**(몸/머리카락/옷/무기가 같은 프레임 크기로 따로 있는 것)이면 이 구조를 그대로 씁니다.
완성형 캐릭터만 있는 팩이면 직업별 변형 몇 종 중 무작위 + 팔레트 교체로 대체합니다.

## 하드코어 장치

- **결과는 전투 시작 순간에 확정·저장**됩니다. 전투는 시드로 결정되므로 화면에서 보는 전투와 결과가 같습니다 (300판 검증).
  패배가 보이기 시작할 때 앱을 꺼도 사망은 되돌릴 수 없습니다.
- 중상 영웅은 진형 자리를 유지하지만 회복 전에는 출전하지 않습니다. 빈 자리만큼 위험도가 바로 올라갑니다.

## 임시 규칙 (이후 단계에서 교체)

- **모집 (임시·무료)**: 영웅 탭에서 무료로 1명씩 모집 (최대 12명). 4단계 모집소로 교체
- 중상 회복 5분, 빠른 회복은 2분 30초 (GDD 16 미정 → 임시값, `src/data/heroes.ts`의 `INJURY_MS`)
- 피로 상태는 아직 없음 (GDD 3.2) → 기지(숙소)와 함께
- 패배 후 광고 부활은 5단계

## 밸런스 (npm run sim, 각 층 600판, 레벨 = 층)

| 층 | 기준 파티 승률 | 무작위 영웅 승률 |
|---|---|---|
| 1~3 | 100% | 100% |
| 4 | 99.7% | 99.7% |
| 5 중간보스 | 83% | 93% |
| 6~9 | 91~100% | 93~99% |
| 10 메인보스 | 69% | 81% |

무작위 영웅은 특성이 대부분 이득이라 기준 파티보다 조금 강합니다. 플레이 감각을 보고 조정.

## 플레이하며 확인할 것

- [ ] 영웅을 잃었을 때 아쉬운가 (이름·외형·특성이 애착을 만드는가)
- [ ] 위험도 "높음/매우 높음"에서 도전을 망설이게 되는가
- [ ] 중상 5분이 적당한가 (너무 짧으면 긴장 없음, 길면 지루함)
- [ ] 낮은 층에서 신규 영웅을 키우는 흐름이 귀찮지 않은가
- [ ] 추모의 벽을 다시 보게 되는가
