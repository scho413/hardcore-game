# 2단계 — 영웅 생성 + 영구 사망 + 쓰러짐 규칙 + 귀환 + 추모의 벽

> GDD 15장 마일스톤 2. 완료 기준: **영웅을 잃는 긴장감 확인**

## 들어간 것

| 항목 | 내용 |
|---|---|
| 랜덤 영웅 | 이름(종족별 음절), **종족**, 직업, 특성 1~2개, 개체값(능력치 ±8%), 외형 |
| 종족 | 인간, 바바리안, 엘프, 드워프, 수인(토끼·고양이·강아지·곰). 고유 특성 + 천적 계열 (GDD 3.4.1) |
| 외형 | 32×32 부위 조합. 같은 외형은 생성하지 않음 (아래 "외형" 참고) |
| 얼굴 아이콘 | 스프라이트의 머리 부분을 잘라서 사용 (결과 화면, 추모의 벽) |
| 구간 테마 | 10층마다 테마. 1~10층 **고블린 소굴**: 고블린 전사·궁수·주술사·폭탄병, 늑대 기수, 홉고블린, 5층 고블린 족장, 10층 고블린 왕 |
| 적 아이디어 | 20종을 8개 계열로 데이터·그림만 준비. 이후 테마에서 골라 씀 |
| 천적 | 속성(불/물/바람) 삭제. 종족마다 천적 계열에 피해 +25% |
| 정찰 숨김 | 처음 도전하는 층은 적 구성·위험도가 "???". 한 번 도전(실패 포함)하면 공개 |
| 특성 | 좋음 7 / 나쁨 8 / 양면 5 + 전투 획득 3 + 극복 2. 수치형, 태어날 때 0~2개, 최대 4개 (GDD 3.5) |
| 특성 변화 | 트라우마(계열), 역전의 용사, ○○ 사냥꾼 획득 / 겁쟁이 → 용기, 이기적임 → 헌신, 트라우마 극복 |
| 진형 | 기본·방패벽·쐐기·산개·돌격 (GDD 4.1.1) |
| 전투 역할 | 직업마다 2~3개 (기사 수호/공격, 사제 치유/공격/축복 등). 영웅 상세에서 변경 |
| 일대기 | 영웅 상세와 추모의 벽에서 보기. 출전·돌파·중상·특성 변화·사망 원인 기록 |
| 쓰러짐 규칙 | 승리 → 쓰러진 영웅 **중상** (5분 뒤 회복). 패배 → 쓰러진 영웅 **전원 사망** |
| 귀환 | 층을 클리어하면 무조건 귀환. 클리어한 층 + 다음 층 중에서 골라 도전 |
| 경험치 | 층 클리어 시 참여 영웅 전원 `100 × 층` 획득, 다음 레벨까지 `100 × 현재 레벨` |
| 추모의 벽 | 도감 탭. 얼굴, 이름, 직업·레벨, 최고 도달 층, 사망 층, 날짜 |
| 화면 | 하단 탭 (영웅 / 탑 / 도감, 기지·던전은 "준비 중"), 영웅 목록·상세, 진형 칸별 영웅 선택창 |

## 외형

`src/art/heroArt.ts`가 32×32 영웅을 레이어로 쌓아서 그립니다.

| 레이어 | 선택지 |
|---|---|
| 종족 머리 | 피부/털 색 4~6종 × 종족 8갈래, 엘프 뾰족 귀, 수인 귀(토끼 접힘 포함·고양이·강아지·곰)와 주둥이, 드워프 큰 코 |
| 머리카락 | 11가지 모양 × 12가지 색 (종족별 출현 색 다름) |
| 얼굴 | 눈 6종 × 눈동자 색 7, 눈썹 5종, 입 6종 |
| 수염 | 드워프는 항상(긴/땋은/넓은), 바바리안·인간은 확률 |
| 표식 | 흉터, 주근깨, 홍조, 안대, 점, 문신, 전투 물감(바바리안), 수염 털(고양이) |
| 직업 | 의상(갑옷/가죽/튜닉/로브), 머리 장비(투구·뿔 투구·후드·마법 모자·후광 등), 무기 2~3종, 옷 색 10 × 보조색 10 |

같은 종족·직업에 모든 선택지가 같은 영웅은 다시 뽑습니다 (죽은 영웅 포함).
`npm run dev` 후 `/tools/faces.html`에서 무작위 영웅을 한 번에 볼 수 있습니다 (`?mode=face`는 얼굴 아이콘, `?mode=monsters`는 적 전체).

### 에셋 팩으로 바꿀 때

`heroArt.ts`의 각 `draw*` 함수가 레이어 하나입니다. 이 함수를 "같은 좌표에 레이어 시트 한 장 그리기"로 바꾸면 구조는 그대로 갑니다.

에셋 팩을 고를 때 **부위가 레이어로 나뉜 팩**(몸/머리카락/옷/무기가 같은 프레임 크기로 따로 있는 것)이면 이 구조를 그대로 씁니다.
완성형 캐릭터만 있는 팩이면 직업별 변형 몇 종 중 무작위 + 팔레트 교체로 대체합니다.

## 하드코어 장치

- **결과는 전투 시작 순간에 확정·저장**됩니다. 전투는 시드로 결정되므로 화면에서 보는 전투와 결과가 같습니다 (300판 검증).
  패배가 보이기 시작할 때 앱을 꺼도 사망은 되돌릴 수 없습니다.
- 중상 영웅은 진형 자리를 유지하지만 회복 전에는 출전하지 않습니다. 빈 자리만큼 위험도가 바로 올라갑니다.

## 임시 규칙 (이후 단계에서 교체)

- **모집 (임시·무료)**: 영웅 탭에서 무료로 1명씩 모집 (최대 12명). 4단계 모집소로 교체
- 중상 회복 5분, 빠른 회복은 2분 30초 (GDD 16 미정 → 임시값, `src/data/heroes.ts`의 `INJURY_MS`)
- 피로 상태는 아직 없음 (GDD 3.2) → 기지(숙소)와 함께
- 패배 후 광고 부활은 5단계

## 밸런스 (npm run sim, 각 층 1000판, 레벨 = 층, 무작위 종족·특성 영웅, 기본 진형·기본 역할)

| 층 | 적 | 승률 | 승리 시 생존 |
|---|---|---|---|
| 1 | 고블린 전사 ×3 | 100% | 5.0 |
| 2 | 고블린 전사 ×2, 궁수 | 100% | 5.0 |
| 3 | 고블린 전사, 홉고블린, 궁수 ×2 | 100% | 4.8 |
| 4 | 고블린 전사, 늑대 기수, 홉고블린, 주술사, 궁수 | 93% | 4.3 |
| 5 중간보스 | 고블린 족장 + 전사 ×2 | 77% | 3.7 |
| 6 | 홉고블린 ×2, 늑대 기수, 주술사, 폭탄병 | 92% | 4.1 |
| 7 | 늑대 기수 ×2, 홉고블린, 궁수 | 89% | 3.3 |
| 8 | 홉고블린 ×2, 늑대 기수, 폭탄병, 주술사 | 86% | 3.8 |
| 9 | 홉고블린 ×2, 늑대 기수, 폭탄병, 전사 | 88% | 3.6 |
| 10 메인보스 | 고블린 왕 + 홉고블린, 전사 | 58% | 2.9 |

고블린 소굴은 전부 녹색족이라 **인간(천적)이 많을수록** 승률이 크게 오릅니다 (전원 인간 기준선이 무작위 파티보다 강함). 테마 설계대로의 효과입니다.
진형·역할을 상황에 맞게 바꾸면 더 오릅니다.

## 플레이하며 확인할 것

- [ ] 영웅을 잃었을 때 아쉬운가 (이름·종족·외형·특성이 애착을 만드는가)
- [ ] 추모의 벽에서 얼굴이 서로 충분히 달라 보이는가
- [ ] 정보 없이 첫 도전하는 긴장감이 괜찮은가, 아니면 억울한가
- [ ] 천적 종족을 맞춰 편성하게 되는가 (고블린 소굴 = 인간)
- [ ] 진형·전투 역할을 바꿔볼 이유가 느껴지는가
- [ ] 특성 변화(극복, 트라우마)가 결과 화면과 일대기에서 눈에 띄는가
- [ ] 나쁜 특성이 많은 영웅을 어떻게 쓰게 되는가 (버리는 패? 키우는 재미?)
- [ ] 위험도 "높음/매우 높음"에서 도전을 망설이게 되는가
- [ ] 중상 5분이 적당한가 (너무 짧으면 긴장 없음, 길면 지루함)
- [ ] 낮은 층에서 신규 영웅을 키우는 흐름이 귀찮지 않은가
- [ ] 추모의 벽에서 일대기를 열어보게 되는가
