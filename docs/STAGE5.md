## 1. 그림 (PixelLab으로 사용자가 만들고, 코드 연결은 Claude)

### 1.1 지금 들어가 있는 그림 (2026-11-07 적용)

그림은 `src/assets/art/` 폴더 아래에 있어요. 코드 연결은 `src/art/hd.ts` 한 곳에 모여 있습니다.

| 폴더 | 내용 | 게임에서 쓰는 곳 |
|---|---|---|
| `monsters/` | 탑 몬스터 34종, 256×256, 배경 투명 | 전투, 탑 화면, 도감, 던전 목록, 이야기. 텍스처 키 `unit-<id>` |
| `bgs/` | 탑 배경 10장 + 기지 배경 3장, 424×632, 배경 불투명 | 전투 배경 (구간 5장 + 보스 방 5장), 기지 배경 (`bg-castle_1~3`, 숙소 Lv1~3 / 4~6 / 7 이상) |
| `buildings/` | 시설 6종 × Lv1~10 + `bld-lot`(빈 터) + `bld-scaffold`(공사 중) | 기지 마을, 시설 창 |
| `weapons/` | 직업 5개 × common/fine/superior (= 재료 단계 1/2/3). 기사는 방패와 검을 따로 | 무기 아이콘. 등급(일반~초월)은 뒤의 빛 색으로 구분 |
| `consumables/` | 물약 7종 | 연금소. 기력 물약 = `potion_stimulant`, 치료 물약 = `potion_panacea`, 해독제 = `potion_antidote` |

**파일 이름 규칙**
- 파일 이름은 코드의 id와 같게 짓습니다.
- 다른 이름으로 올렸다면 `hd.ts`의 `MON_ALIAS`, `BLD_ALIAS`, `POTION_FILE`에서 연결합니다.
- 지금 걸려 있는 예외는 `goblin_hob` → `hobgoblin`, `goblin_wolf_rider` → `wolf_rider`, `smith_*` → `smithy` 입니다.

**크기 맞추기**
- 그린 그림은 예전 도트(16px)보다 커서, `fitScale()`이 예전 배율을 실제 배율로 바꿉니다.
- 몬스터마다 덩치가 다르기 때문에 `MON_SIZE`로 크기를 따로 줍니다. 그림은 모두 칸을 꽉 채우고 있습니다.
- 줄일 때는 밉맵으로 부드럽게 처리합니다 (`main.ts`의 `render.mipmapFilter`).
- 그림이 없는 것은 코드로 찍은 예전 도트가 그대로 나옵니다.

**기지 배치**
- `bg-castle` 그림 속 광장의 중심(424×632 기준 212, 355)을 기준점으로 씁니다.
- 건물 여섯 채는 `TownScene`의 `PLOTS`에 적힌 위치에 놓입니다.

### 1.2 만들어야 할 그림

모든 그림의 공통 규칙
- 크기는 **256×256**, 배경 **투명 PNG**로 만듭니다. 배경 그림만 예외로 **424×632, 불투명**입니다.
- 이미 있는 그림을 PixelLab의 스타일 참고 이미지로 넣어서 화풍을 맞춥니다.
  - 몬스터 → `monsters/goblin.png`
  - 물약 → `consumables/potion_antidote.png`
  - 배경 → `bgs/goblin_cave.png`
- 정면 또는 살짝 비스듬한 정면, 서 있는 자세, 그림 하나가 칸 가운데를 꽉 채우게 만듭니다. 덩치 차이는 코드에서 줍니다.
- 파일 이름은 아래 표의 id를 그대로 씁니다.

#### A. 영웅 (가장 큼, 꼭 시험부터)

목표는 **영웅마다 이름과 외형이 모두 다르게** 나오는 것입니다. 머리·몸통·다리를 따로 그려 조립하는 방식은 쓰지 않습니다. AI로 따로 만든 부위는 각도와 비율이 달라서 이음새가 어긋나기 때문입니다. 대신 아래 방식으로 갑니다.

1. **통짜 기본 그림**
   - 종족 8개 × 성별 2 × 직업 5 = **조합 80개**입니다. 조합마다 얼굴이나 머리 모양이 다른 버전을 2~3장 만들어 모두 160~240장이 됩니다.
   - 종족: 인간 `human`, 바바리안 `barbarian`, 엘프 `elf`, 드워프 `dwarf`, 수인 4종(토끼 `rabbit`, 고양이 `cat`, 개 `dog`, 곰 `bear`)
   - 직업과 무기: 기사 `knight`(검과 방패), 전사 `warrior`(도끼), 궁수 `archer`(활), 마법사 `mage`(지팡이), 사제 `priest`(홀). 무기는 `weapons/`의 그림과 같은 종류로 맞춥니다.
   - 파일 이름: `heroes/<종족>_<성별 m|f>_<직업>_<번호>.png` (예: `heroes/elf_f_archer_2.png`)
2. **색 바꾸기 (코드)**
   - 그림마다 머리카락, 피부(수인은 털), 옷 주색, 옷 보조색 영역을 나눠 둡니다.
   - 게임이 영웅을 뽑을 때 각 영역에 다른 색을 입힙니다. 그래서 한 장에서 수백 가지 외형이 나옵니다.
   - 지금 코드의 `Look`(머리색·피부·옷 색)과 겹치는 외형 검사(`lookSignature`)를 그대로 씁니다.
   - **그림에서 지킬 것:**
     - 머리카락, 피부, 옷이 각각 한 계열 색이어야 합니다. 여러 색이 섞인 옷이나 머리는 피합니다.
     - 영역끼리 색이 확실히 달라야 합니다. 예를 들어 갈색 머리에 갈색 가죽옷은 피합니다.
3. **작은 장식 (나중에)**
   - 흉터, 안대, 머리띠, 귀걸이 같은 것을 따로 그려서 얼굴 위치에 얹습니다.
   - 그림마다 얼굴 위치(눈높이와 얼굴 중심)를 기록해 둡니다.
4. **얼굴 초상화**
   - 카드, 결과 창, 대사창, 도감은 전신 그림에서 얼굴 부분을 잘라 씁니다 (`face-<id>`).
   - 그래서 **투구, 두건, 가면으로 얼굴을 가리면 안 됩니다.** 얼굴은 그림 위쪽 1/3 안에 오게 합니다.
5. **진행 순서**
   - 먼저 **인간 남자 5직업 × 1장 = 5장**을 만듭니다.
   - Claude가 색 바꾸기를 붙여서 같은 그림에서 영웅이 얼마나 다르게 나오는지 보여 줍니다.
   - 사용자가 확인한 뒤 나머지 조합을 만듭니다.
6. **연결할 곳**
   - `src/art/textures.ts`의 `ensureHeroTextures()`가 `hero-<id>`와 `face-<id>`를 만듭니다. 이 함수를 그린 그림 + 색 바꾸기로 바꿉니다.
   - 전투(`BattleScene.createView`)는 영웅을 `32 × 3`px 기준으로 놓습니다. 몬스터처럼 `fitScale`로 맞춥니다.
   - 안내자 **기록관 오렌**(드워프 남자 사제, `tutorial/overlay.ts`의 `guideHero`)도 같은 방식으로 나옵니다. 따로 한 장 그려도 됩니다.

#### B. 던전 (몬스터 12종 + 배경 3장)

던전은 3곳이고 각 10층입니다 (`src/data/dungeons.ts`).

| 던전 | 배경 파일 | 약한 적 | 강한 적 | 10층 보스 |
|---|---|---|---|---|
| 버려진 광산 `mine` | `bgs/dungeon_mine.png` | `slime`, `spider`(있음) | `troll`(있음) | `ogre` |
| 어두운 숲 `forest` | `bgs/dungeon_forest.png` | `wolfkin`, `hyena` | `gnoll` | `gnoll_chief` |
| 마석 동굴 `cave` | `bgs/dungeon_cave.png` | `imp`, `ghoul` | `naga`, `succubus` | `lich` |

- 새로 그릴 몬스터는 `slime`, `ogre`, `wolfkin`, `hyena`, `gnoll`, `gnoll_chief`, `imp`, `ghoul`, `naga`, `succubus`, `lich`로 **11종**입니다. `ogre`는 탑의 `ogre_brute`와 겉모습이 구분돼야 합니다. 던전 보스라서 더 크고 위압적으로 그립니다.
- 탑 몬스터 중 빠진 **`goblin_bomber`(고블린 폭탄병, 후열 원거리)** 1종도 같이 그립니다. 프롬프트는 이미 사용자에게 전달했습니다.
- 그래서 몬스터는 모두 12종입니다.
- 배경 3장은 탑 배경처럼 위쪽에 적(벽이나 안쪽), 아래쪽에 아군(바닥)이 서는 구도로 그립니다.
- **연결할 곳:** `hd.ts`의 `towerBg()`처럼 던전용 `dungeonBg()`를 만들고, `BattleScene.drawBackground()`에서 던전일 때 씁니다. 지금은 던전이면 예전 벽돌 배경이 나옵니다.

- 파일 이름: `materials/<id>.png`. 아이콘이라 작게 보이므로 실루엣이 단순하고 또렷해야 합니다.
- 단계가 오를수록 더 귀해 보이게 그립니다. 예를 들어 1단계는 거친 덩어리, 3단계는 빛나는 결정입니다.
- **연결할 곳:** `src/art/itemArt.ts`의 `matIcon()`. 무기처럼 그림이 있으면 그것을 쓰고 `fitScale`로 맞춥니다. 재료 아이콘을 쓰는 화면은 대장간, 던전, 결과 창, 기지 시설 창입니다.

#### D. 물약 2종

- `consumables/potion_might.png`: 힘의 영약 (다음 전투 공격력 +10%). 진홍·자주색.
- `consumables/potion_guard.png`: 수호의 영약 (다음 전투 방어력 +15%). 파란색.
- 프롬프트는 이미 사용자에게 전달했습니다. 그림이 오면 `hd.ts`의 `POTION_FILE`에 두 줄만 추가하면 됩니다.
- 이미 있는 `potion_hp_s/m/l`, `potion_fire_resist`는 게임에 아직 없는 물약입니다. 사용자가 쓸 예정이라 효과를 새로 기획해야 합니다.
